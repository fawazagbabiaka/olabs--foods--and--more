# OLAB'S FOODS & MORE

Website files for OLAB'S FOODS & MORE.

## Files
- `index.html` — main website
- `images/` — all product images used by the website

## Important
Keep the `images` folder in the same location as `index.html`. The website now loads product images from this folder instead of storing huge base64 images inside the HTML.

## GitHub Pages
Upload `index.html` and the entire `images` folder to the repository root. The main file must remain named `index.html`.

Do not upload only `index.html` without the `images` folder, otherwise product pictures will not appear.
